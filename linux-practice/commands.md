# Linux Basics - Day 1

## 1. pwd - Present Working Directory
Nuvvu ippudu ekkada unnavo chupistundi
> Example: pwd

## 2. ls - List files
Folder lo em files unnayo chupistundi
> Example: ls -la (antha detailed ga)

## 3. cd - Change Directory
Oka folder nundi inkoka folder ki velladaniki
> Example: cd linux-practice

## 4. mkdir - Make Directory
Kotta folder create cheyadaniki
> Example: mkdir my-folder

## 5. touch - Create empty file
Kotta empty file create cheyadaniki
> Example: touch test.txt

## 6. echo - Text rayadaniki
File lo text rayadaniki
> Example: echo Hello DevOps > test.txt

## 7. cat - File chadavadaniki
File lo em undo chupistundi
> Example: cat test.txt

## 8. cp - Copy
File ni copy cheyadaniki
> Example: cp test.txt copy.txt

## 9. mv - Move / Rename
File peru marchadaniki
> Example: mv test.txt new.txt

## 10. rm - Remove
File ni delete cheyadaniki
> Example: rm new.txt

## 11. grep - Search
File lo oka word ni vetakadaniki
> Example: grep "error" log.txt

## 12. chmod - Permissions
File ki permission ivvadaniki
> Example: chmod +x script.sh

## 13. ps - Processes
Running processes chudataniki
> Example: ps aux
